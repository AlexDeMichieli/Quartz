# Quartz

Quartz is an online gallery built with Django and connected to Amazon S3 and Postgres.

The app is deployed at https://qwartz.herokuapp.com/

## Hello World

This project includes a simple "Hello World" implementation in Python:

### Standalone Script
Run the standalone Python script:
```bash
python3 hello_world.py
```

### Django View
A "Hello World" view is available at the `/hello/` endpoint:
- URL: `/hello/`
- View: `quartz_app.views.hello_world`
- Returns: "Hello World!" as plain text

### Testing
Run the test script to verify the hello world functionality:
```bash
python3 test_hello_world.py
```
